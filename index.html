Inicio

Esta página fue creada para registrar los datos de los clientes de una agencia de viajes.

El objetivo es tener la información de los clientes de una manera sencilla y organizada.

Problema

Algunas agencias de viajes registran la información de sus clientes en libretas, hojas de cálculo o documentos separados.

Esto puede provocar pérdida de información, errores y dificultad para encontrar los datos.

Solución

La solución propuesta es una página web sencilla para registrar los datos principales de los clientes.

  • Registrar clientes.
  • Validar los datos.
  • Mostrar un mensaje de registro.
  • Consultar los clientes registrados.

Funcionamiento

El usuario debe llenar el formulario con los datos del cliente y presionar el botón "Guardar".

Si falta algún dato, el sistema muestra un mensaje de error. Si todos los datos están completos, aparece un mensaje indicando que el cliente fue registrado correctamente.
