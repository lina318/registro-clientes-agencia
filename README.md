# Registro de Clientes para una Agencia de Viajes

Este proyecto consiste en una página web sencilla creada para registrar los datos de los clientes de una agencia de viajes.

La página permite ingresar información como nombre, apellido, teléfono, correo electrónico y destino de viaje. También cuenta con una validación mediante JavaScript para comprobar que los datos estén completos.

El proyecto busca facilitar el registro de clientes y evitar problemas como pérdida de información, errores en los datos o dificultad para encontrar la información de los clientes.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- GitHub Pages

## Objetivo

Crear una solución tecnológica sencilla que ayude a una agencia de viajes a organizar mejor la información de sus clientes.
